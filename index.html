Política de privacidad de SIGA – Gestión Agrícola

Aplicación: SIGA – Gestión Agrícola
Identificador: com.jcz.gestionagricola
Desarrollador: JCZ-TECNOLOGY
Última actualización: 16 de noviembre de 2026

1. Finalidad de la aplicación

SIGA – Gestión Agrícola permite organizar información sobre fincas, lotes, cultivos, productos, proveedores y operaciones agrícolas. Su diseño principal contempla el funcionamiento sin conexión y el almacenamiento local mediante una base de datos del dispositivo.

2. Datos que introduce el usuario

Dependiendo de las funciones utilizadas, el usuario puede introducir nombres y datos de contacto de proveedores, información de fincas y lotes, productos, compras, movimientos de inventario, aplicaciones y notas. Algunos registros pueden contener información personal introducida voluntariamente por el usuario.

3. Almacenamiento y uso

Los datos registrados se utilizan para realizar las funciones de administración agrícola y se almacenan principalmente en el dispositivo. El usuario controla la información que ingresa. La instalación o distribución mediante Google Play está sujeta al procesamiento de datos propio de Google Play, conforme a sus políticas.

4. Acceso, envío y terceros

La funcionalidad principal de SIGA ha sido diseñada para uso offline. Antes de afirmar que ninguna información sale del dispositivo, se verificarán las bibliotecas de terceros, los servicios activados, las funciones de licenciamiento, las copias de seguridad y el comportamiento de red de la versión publicada. Si se habilitan funciones que transmitan datos, esta política se actualizará para informar los datos, destinatarios y finalidades correspondientes.

5. Permisos

La aplicación puede solicitar permiso para mostrar notificaciones de tareas o recordatorios. También puede utilizar el aviso de reinicio del dispositivo para gestionar recordatorios, si esa función está activa. Los permisos que solicite la versión instalada dependerán de las funciones implementadas.

6. Conservación y eliminación

Los registros locales se conservan hasta que el usuario los modifique o elimine mediante las funcionalidades disponibles, o hasta que se eliminen los datos locales de la aplicación mediante los controles del sistema operativo. La desinstalación puede provocar la pérdida definitiva de registros locales si no existe una copia de seguridad recuperable. La eliminación de registros vinculados a operaciones históricas puede estar limitada para preservar la integridad de inventario y contabilidad.

7. Seguridad

La aplicación utiliza el almacenamiento proporcionado por Android y su base de datos local. Se recomienda proteger el dispositivo con bloqueo de pantalla y mantener copias de seguridad seguras cuando la función esté disponible. Ninguna medida tecnológica garantiza protección absoluta.

8. Niños

SIGA – Gestión Agrícola está orientada a la administración de actividades agrícolas y no está diseñada específicamente para niños.

9. Cambios de esta política

Podremos modificar este documento cuando cambien las funciones o las prácticas de tratamiento de datos de SIGA. La fecha de actualización se mostrará al inicio de esta página.
